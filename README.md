# Продуктовая разработка: подготовка к зачёту

Сайт-конспект по курсу «Разработка программного продукта»: 8 тем (по одной на занятие), в каждой есть:

- «Что мы изучим»: краткий план темы;
- пошаговое объяснение материала;
- формулы с разбором каждого компонента;
- интерактивные задания (карточки, классификация, порядок этапов, калькуляторы, тренажёр игры Market Fit);
- шпаргалка;
- тест с подсказками и объяснением ошибок.

Сайт: https://mmarmar4028-gif.github.io/studying_product.dev/

Игры профессора для практики: https://productgamer.ru/

Готово: все 8 тем и пробный зачёт (24 случайных вопроса из всех тем, нужно 15 правильных).
